# Kiwi & Colibri website

Luxury equestrian house website. Static single-page site — no build step, no dependencies.

**View it:** open `index.html` in a browser.

```
index.html       the site (markup for all views)
css/styles.css   styling
js/main.js       behaviour (view router, looks, wishlist, bag)
assets/          img/ video/ fonts/ used by the site
source/          original photography & print files (not used by the site)
archive/         old self-contained builds, superseded by index.html
```
