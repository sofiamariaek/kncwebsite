# KC Website — Project Instructions

## Git workflow (always follow)

- This folder is the `kncwebsite` git repository.
- Whenever a file in this project is created or edited, commit the change to git and push it to GitHub in the same session. Never leave edits uncommitted.
- Use short, descriptive commit messages (e.g. "Update hero section in KC-Site-2026_40.html").
- `KC-Site-2026_41-luxury.html` is intentionally excluded from the repository via `.gitignore` — never commit it.
